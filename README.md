# João Gonçalves — Portfolio

A bilingual portfolio built with React, TypeScript, Vite, and Tailwind CSS. The English site is served at `/` and the Portuguese version at `/pt/`.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run check
npm run build
```

The production build is written to `dist/` and includes the English, Portuguese, and 404 pages.
